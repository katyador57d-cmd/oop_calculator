Название проекта:
    ООП Продукт
Описание:
Это первая задача по объектно-ориентированному программированию. Необходимо
переписать знакомый проект «Калькулятор корзины покупок» с нуля — но теперь в
ООП-стиле, используя классы вместо функций и массивов.
Функционально программа делает то же самое: пользователь управляет корзиной
через текстовое меню, добавляет и удаляет товары, видит итоговый чек со скидкой.
Но внутренняя архитектура меняется полностью — см. раздел «Было → Стало».
Цель задачи — понять фундаментальные концепции ООП на знакомом примере: что
такое класс и объект, как работают public/private поля, зачем нужен конструктор, что
делает readonly, и почему инкапсуляция важнее публичного доступа.

Технологии:
PHP 8.1+;
Строга типизация declare(strict_types =1)
